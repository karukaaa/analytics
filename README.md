The library offers 3 methods for analyzing user purchases:
1. getMostPopularItems() to find frequently ordered menu items across all users.
2. getMostPopularCafes() to determine which cafes receive the most orders.
3. getMostOrderedItemsForCafe(cafeId) to analyze top-selling items within a specific cafe.

The library integrates seamlessly with Firebase Firestore and helps visualize user behavior through backend analytics.
